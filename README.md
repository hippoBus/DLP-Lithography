# DLP Lithography

## Introduction

An affordable lithography alternative using projector IP 
from Texas Instrument’s DLP for Ultraviolet (UV) 3D Printers, [DLP301S](https://www.ti.com/product/DLP301S).

Custom optical engine simulated using Ansys Zemax OpticStudio, 
and PCB design on KiCad v10.0.5

## Specs / Parts
- DLP Chipset:
  - TI [DLP301S](https://www.ti.com/product/DLP301S) DMD
  - TI [DLPC1438](https://www.ti.com/product/DLPC1438) controller
  - TI [DLPA2000](https://www.ti.com/product/DLPA2000) PMIC
